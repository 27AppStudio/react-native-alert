# react-native-alert

Native alerts and text prompts for React Native in your app's tint: UIAlertController on iOS, Material 3 dialogs on Android.

## Installation


```sh
npm install react-native-alert
```


## Usage


```js
import { multiply } from 'react-native-alert';

// ...

const result = multiply(3, 7);
```
